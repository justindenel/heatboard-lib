# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which is incorporated here by reference.

In short: be respectful, welcome different viewpoints, give and accept constructive feedback gracefully, and focus on what is best for the community. Harassment, discrimination, personal attacks and publishing other people's private information are not accepted.

## Reporting

To report unacceptable behaviour, contact the maintainer privately through [GitHub](https://github.com/justindenel) (a private message or a [private security advisory](https://github.com/justindenel/heatboard-lib/security/advisories/new) if no other channel is available). Reports are handled confidentially.

## Enforcement

Maintainers may edit or remove comments, commits, issues and pull requests that do not follow this code, and may temporarily or permanently ban a contributor. The enforcement guidelines of the Contributor Covenant describe the possible consequences.
