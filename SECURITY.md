# Security policy

## Supported versions

The libraries are in 0.x: only the latest published version of `@heatboard/core` and `@heatboard/react` receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability** (private vulnerability reporting). Include the affected package and version, a description of the impact, and the steps or a minimal example to reproduce it.

You can expect an acknowledgement within a few days. A fix is prepared privately, released, and disclosed in a security advisory once users can update.

## Scope

This repository holds the libraries and their demo site. The hosted platform at <https://heatboard.denel.dev> is a separate project; report its issues the same way and mention that they concern the platform.
